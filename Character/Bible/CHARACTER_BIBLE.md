# VROO Vehicle Character Bible v1.0

## 핵심 철학
자동차는 사용자의 디지털 캐릭터다. 등급이 올라가도 같은 차량 DNA가 유지되어야 한다.

## 공통 DNA
- V 형태의 전면 시그니처
- Black / Graphite 차체
- Gold 성장 포인트
- 낮고 넓은 실루엣
- 차량 등급별 조명과 공력 파츠의 단계적 강화

## 성장 단계
1. Basic / Common
2. Street / Rare
3. Sport / Epic
4. Performance / Legendary
5. VROO Heritage / Mythic

- 캔버스: 1200×600
- 투명 배경

- Garage용 기본 구도는 front_45
- 실존 브랜드 로고와 고유 디자인을 복제하지 않음
