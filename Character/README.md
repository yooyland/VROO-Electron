# VROO Character System

이 폴더 전체를 `D:\VROO_Electron\Character`에 덮어쓰기 또는 병합해서 사용합니다.

## 지금 바로 볼 수 있는 것
- `Vehicles/*/views/front_45.svg` : 5단계 차량 임시 캐릭터
- `Integration/examples/garage-character-demo.html` : 브라우저 테스트
- `Data/vehicle-character-manifest.json` : 앱에서 읽을 차량 데이터
- `Integration/js/vroo-character-loader.js` : 캐릭터 로더 예제
- `Integration/css/vroo-character.css` : Hero 표시용 CSS

## 중요
현재 SVG는 개발 연결과 화면 검증을 위한 **교체 가능한 초기 캐릭터**입니다.
최종 차량 원화가 확정되면 같은 파일명과 SVG group ID를 유지하며 교체하세요.
