# VROO PROJECT BRAIN v2.0 RULES

## Evidence hierarchy

1. Git status and tracked repository state
2. Automated validation results
3. Work Queue states
4. Architecture and domain documentation
5. File/module inventory
6. Human estimates

## Progress interpretation

The score is an operational confidence estimate, not a production-readiness claim.

- 35% required project signals
- 25% Git integration and commit state
- 20% Work Queue completion
- 20% change-risk and validation readiness

## Safety rule

Project Brain may recommend and prepare work. It must not reset, delete, force-checkout,
merge, or overwrite user work without explicit approval.
