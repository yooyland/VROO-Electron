# CONSOLE_USER_GUIDE

## 실행

```powershell
npm run console
```

## 데모 로그인

1. 역할 카드를 선택한다. (실계정 로그인 아님)
2. 상단 **DEMO ROLE SWITCHER** 로 역할 전환 가능
3. 로그아웃 시 로그인 화면 복귀

잘못된 `vroo.console.*` localStorage 값은 자동으로 로그인 화면으로 복구된다.

## 역할별 메뉴 (요약)

| 역할 | 주요 메뉴 |
|------|-----------|
| 최고 관리자 | 전체 |
| 운영 관리자 | 회원·차량·GRID·신고·상품·혜택·공지 (시스템 관리 제한) |
| 제휴사 관리자 | 자기 상품·혜택·제휴사·정산·통계 |
| 제휴사 직원 | 상품·혜택 조회/제한 관리, 정산 설정 변경 불가 |
| 상담원 | 문의·신고·사고·회원 조회 |
| 분석가 | 통계 (수정 없음) |
| 개발자 | 시스템·권한·로그성 화면 |

## planned 화면

멤버십·주문 등 `planned` 메뉴는  
**“상용화 단계에서 제공될 예정”** 안내만 표시하며 실동작처럼 보이지 않는다.

## 주의

- 상태 변경은 데모 메모리뿐
- 실결제·실정산·실보험·외부 사고 전송 없음
